先读这一条。真实打击清单属最高机密。本图只基于公开地理、工业布局、人口、风向和军事地理常识做桌面推演，不代表任何真实计划、情报结论或官方判断。全面核交换下，长三角是全球目标最密集的区域之一，不存在真正安全的地方；本图只在“有限打击、边缘波及、战后头几个月求生”这三种情境下有意义。战时请以当地人防部门指令为准。

1. 危险度怎么算

每个区县取驻地坐标，对每个公开目标计算三项威胁，再按权重合成 0–100 的相对指数：

54%直接打击 / 冲击波按假设当量 150 kt 的 5 psi 与 1 psi 半径衰减
32%放射性沉降按下风向锥形羽流、横风宽度与距离衰减
14%次生灾害石化/化工毒云、核电污染、坝下洪水、港口与工厂火灾

危险度是相对指数，不是辐射剂量，也不是伤亡概率。它回答的是“哪里更可能被波及、波及后更麻烦”，而不是“哪里绝对安全”。县级工业产值没有统一公开口径，模型用“目标清单 + 人口密度”作为目标价值代理；它不是工业产值排名。

2. 生存条件与推荐度

34%低危险度危险度越低越好
26%地形遮蔽SRTM 90 m 采样：平均海拔 + 17 点起伏
22%自持力人口密度、农业基础、水源与小水电潜力
10%可达性距上海的公路时间估算
8%公共服务县城/县级市/市辖区的医疗与接待能力代理

综合推荐 = 0.58 × 安全 + 0.42 × 生存条件 − 平原惩罚。平原惩罚用于纠正“离目标远但无地形遮蔽”的误导。

可达推荐是在综合推荐上再扣除从所选出发地到该县的距离与时间成本。它回答“我现在从这里出发，现实中最值得去哪儿”。

3. 三种情景

  • 全面交换：所有目标计入，适合看最坏情况。
  • 有限打击：只计核设施、军港、指挥、机场、港口、铁路、钢铁，且降低民用机场与港口的权重。
  • 边缘波及：假定主要爆心在邻近区域，只计算沉降、化工与水利次生灾害，适合看“没直接被炸但被波及”的情形。

4. 风向假设

华东冬季盛行西北风，夏季东南风，春秋多东北风。图中的沉降热区会随风季切换而重算。真实核爆后局地风、对流雨和地形会显著改变沉降，本图只给大方向。

5. 数据来源

  • 阿里云 DataV.GeoAtlas 行政区划边界（2024）——625 个县级单元。
  • 第七次全国人口普查分县资料（2020）——常住人口；部分新设/合并区按公开口径估算。
  • OpenTopoData / SRTM 90 m——每县 17 点地形采样。
  • 公开报道的核电、港口、钢铁、石化、化工园区、工厂、机场、水利、铁路编组设施位置（坐标约 1–5 km 误差）。
  • 化工园区/化工企业 107 个（⚗）、大型工厂 28 个（▤），缩放地图后按级别逐步显示。
  • Natural Earth 10m 河流/湖泊；OSRM / OpenStreetMap 公路路径（作走廊示意，非官方线位）。
  • 公开气象常识与公开的民防、核防护常识。

6. 分区域速查

上海主城 / 浦东战前 48–72 小时向皖南（黄山—绩溪—泾县）或浙西南；警报发布后原地进入人防，不要上高速。
上海郊区 / 崇明青浦西部只适合短时掩蔽；崇明长江隧桥是单点瓶颈，不建议战时离岛。
苏南（苏锡常宁镇）向皖南或浙西南；避开沪宁走廊、沿江重化带。南京可向皖西大别山。
苏中 / 苏北向沂蒙山或大别山；盐城沿海要防台风与平原沉降；洪泽湖坝下不要停留。
浙北（杭嘉湖）向皖南或浙西南；避开秦山 50 km、杭州湾下风向与嘉兴化工园区。
浙东沿海（甬台温舟）向浙西南或闽北；避开北仑、镇海、三门、三澳；海岛不作为首选。
皖南 / 皖西本地就是目的地；选山腰台地，避开新安江、陈村、港口湾等坝下河谷。
皖中 / 皖北向大别山或皖南；避开合肥、马鞍山、铜陵、芜湖的沿江工业带。
闽东北 / 闽南向闽西北、武夷山；避开沿海港口与福清、宁德、漳州核电下风向。
赣北 / 赣西 / 赣南向铜鼓、修水、资溪、武夷山；避开南昌、九江、向塘枢纽。
鲁中 / 鲁南 / 胶东向沂蒙山、鲁山、五莲；避开济南、青岛、港口群与胜利油田。

这些只是一句话方向，具体到县请点击地图查看“撤离方案”和“可达推荐”。

7. 不能做什么

  • 不能预测真实打击顺序、当量、空爆/地爆、拦截率与政治决策。
  • 不能给出个人辐射剂量、伤亡概率或“绝对安全”结论。
  • 不能替代当地人防工程清单、疏散预案与官方警报。
  • 不能把“危险度低”理解为“不会受影响”。战后真正的杀手往往是水源污染、疫病、饥荒与秩序崩溃。
